Cookie and Browser Storage Policy

Transparency regarding how MortgagePro Global uses cookies and advertising technologies.

Document revision 2026-10-26 · Publisher: REO Technologies. Source observations have their own dates.

Cookies and browser storage have different purposes. A security cookie, a saved display preference and an advertising identifier should not all be described as anonymous or necessary for a repayment calculation.

Calculator operation

The calculator arithmetic runs in the page. You can use an estimate without a website account. The publisher-controlled code does not send financial inputs to an analytics service or store a server-side borrower profile.

The current calculator code does not save a borrower profile or financial entries in localStorage or sessionStorage. A downloaded result is a file you choose to save, rather than an advertising cookie. Browser site-data controls can remove stored provider data where present.

Hosting security

Cloudflare delivers the website and may use security technologies to manage requests and detect abuse. Their operation can depend on the site's hosting settings and the request. We do not claim that a security cookie is set on every visit or that it contains no personal data. See Cloudflare's privacy policy.

The live host also injects a Cloudflare performance beacon. Its measurement requests are distinct from storing your calculator inputs. Read the provider's Web Analytics documentation for its service description. The statement below about no publisher-loaded Google Analytics or Clarity does not mean that this hosting-provider measurement is absent.

Advertising technologies

Google AdSense code is present on content pages. Google and its partners may use cookies and identifiers to provide, measure or personalize ads, subject to the applicable settings and choices. These technologies are not required to calculate principal and interest.

The provider, region and consent state determine which technologies are used and for how long. We do not publish an invented universal cookie-duration table. Google's partner-sites explanation and advertising policy describe its processing.

Optional analytics

This website release does not load Google Analytics or Microsoft Clarity from publisher-controlled code. It does not use session replay to record entries in the calculator. Any future introduction of optional analytics requires a separate review of consent, masking, data fields and disclosures.

Change your choices

Use Privacy Settings to reopen the advertising provider's controls when they are available for your location. If those controls have not loaded on the current page, the link opens the Privacy Settings page, which also links to policy and browser guidance. The availability of a message depends on the site's published provider configuration and regional rules.

The Privacy Settings entry point can load the published Google interface from an ad-free document. It keeps ad requests paused even if consent has already been granted. On eligible content pages, unknown or failed provider state does not resume ad requests, and refusing required storage/vendor permission keeps them paused. These controls do not invent a consent record or prove that an account message has been published.

You can block or clear cookies in your browser and use Google's ad controls. Clearing cookies may also remove saved choices, causing a provider to ask again. Blocking scripts can affect ads or security features.

Questions

Email support@mortgageproglobal.com about a privacy-control problem. Include the page URL and a description of the behavior; leave out private financial information. Read the website privacy policy for contact messages, hosting request data and your rights.
