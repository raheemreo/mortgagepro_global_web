# Phase 4 — trust, source scope and unsupported claims

Implemented 26 October 2026.

- Replaced all 42 legacy hub FAQ answers with scoped explanations. Removed unsupported PMI/DTI/processing-fee/low-equity ranges, obsolete state concession claims, universal European deposit/notary/spread/penalty claims and overbroad insurance/qualification/tax entitlement assertions. Questions were realigned to the revised answers.
- Kept real calculators intact. Unsupported prose is not a justification to alter a working calculation engine without a demonstrated defect.
- Retired the seven parallel `data/rules/*` layers instead of continuing to publish them as independently verified statutes. Each endpoint now explains retirement and links to the active tool reference. No stale NZ LVR speed limits or invented all-Europe tax table remain in that layer. The metadata validator now checks integrity honestly; it does not certify law merely because numbers match a fixture.
- The privacy/cookie source documents now disclose the Cloudflare performance beacon observed on the live host. No retention period, cookie table or anonymity guarantee was invented. Official documentation: https://developers.cloudflare.com/web-analytics/about/ (reviewed 26 October).
- Document revision dates are explicit data, distinct from source observations, policy-effective dates and source retrieval dates. The data-sources explanation now distinguishes an observed overnight rate from a policy-change date. Rebuilding a document does not invent a new fact-verification date.
- Publisher-contact links and educational notices were added earlier; no licence, financial qualification, career history or independent human review was fabricated. The shared Android privacy document and app repository were not changed.

Remaining source scope: reference metadata does not establish every local tax, insurer exception or eligibility condition. Non-reviewed calculator/article pages are explicitly excluded from indexing and ads. They require a later substantive review before admission; this release does not pretend they have received a complete financial/legal sign-off.
